# Developers 模板说明

先读仓库根目录的 `README.md` 或 `README.zh-CN.md`，再按下面顺序读。不要从构建说明推断内容怎么放。

| 文件 | 读它是为了 |
| --- | --- |
| [overview.md](overview.md) | 这个模板是什么、给谁用、什么场合不用 |
| [structure.md](structure.md) | 有哪些页面模板，首页和正文怎么配合，内容从知识库来还是写在页面上 |
| [schema.md](schema.md) | 设置项的字段 id、类型，以及能不能改 |
| [usage.md](usage.md) | 建站之后怎么选布局、内容从哪来、去哪里问 |
| [activation.yml](activation.yml) | 快速开始向导用的编排配方。规则只有三种，文案给人看 |
