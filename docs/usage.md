# 怎么用

1. 用这个模板建一个 wiki 站点，并准备一个知识库。网址或文件导入会同时建知识库并投影过来。
2. 选一套首页：book（书式目录）、documentation（头图加精选卡片）或 portal（栏目卡片加热门页）。三套的子页面都是 `page`。
3. 知识库文章用 `page`。改标题和正文请回知识库，不要在页面上改 `title` 和 `content`。只想列出子页时，把该页换成栏目壳 `page.channel`。
4. API 参考用 `page.api`，填写 `api_document` 或 `api_document_url`。这不是导入正文。
5. 提问入口是 `-/search`。AI 在搜索页右侧作答，首页和文章没有独立 AI 侧栏。

没有示例种子，所以快速开始里不会出现「先用示例体验」。编排方案见 [activation.yml](activation.yml)：手册保持原有章节、按顶层拆成几本手册，或接口和文章先铺平。

## 按目标快速开始

从快速开始选择本模板，或从市场选定模板版本后继续同一流程。可以绑定已有知识库、读取网址、上传文件 / Excel，或从空白知识库写第一篇文章。AI 整理和问答均可跳过。

启动时固定所选版本的具体内容；后续分支更新不会改变这次启动或已经安装的站点。首页布局、Logo 和引导文字使用普通模板设置，完成后仍在正常设置中维护。仅填写新建或尚未填写的值，恢复启动不会覆盖已有修改。

先核对首页、目录、文章、搜索和实际访问范围，再完成启用。知识库同步已经发布内容，完成启用不会增加第二次发布。

本阶段的启动导入只生成普通文档页面；OpenAPI 的专用输入继续在正常页面维护中配置。

绑定已有文章子树时，首页同时展示根文章标题、正文和原有子页面入口；正文仍在知识库维护。绑定整个知识库时，空的根正文不会产生额外内容区块。
